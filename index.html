01 // Situation report

The world is on alert

Two superpowers. Sixteen nations. One battlefield. The Union and the Vanguard are at war, and you command one of them. Build your base, harvest ore, raise an army of tanks, jets, warships and battle robots, then bring it all down on your enemy before they launch first.

A

HD 3D-rendered armies

Every tank, jet, helicopter, warship, soldier and building is rendered from a real 3D model, with national building styles, smooth motion and HD explosions, smoke and missile trails.

B

A real air force

Airfields with parking slots, jets that rearm on the pad, layered air defence, flares, real missile models and bombers. Helicopters reload in the field.

C

Battle robots

Cyborg Troopers, Battle Droids, Railgun Robots, Iron Guards and Tesla Automatons take the field next to classic infantry.

D

Superweapons

Nuclear Missile Silos, the USA's Fatman Strike from its bomber field, ASAT sites and more. Watch the sky.

E

Living weather

Thunderstorms, rain, snow, blizzards, sandstorms, fog and strong winds roll across the map during battle, with a forecast in your sidebar.

F

A modern interface

Reskinned menus, lobby and sidebar, production tabs, hologram placement, detailed unit cards, a battle report and an observer view with live stats.

05 // Deployment orders

Get in the fight

Skirmish against AI from Easy to Brutal, or play multiplayer with friends. Everything the game needs is in the repository: no original Red Alert files, no internet connection required.

  1. Install the .NET 6 SDK

    Download it from dotnet.microsoft.com and run the installer for your system.

  2. Linux only: install the libraries

    The game needs SDL 2, FreeType, OpenAL and Lua 5.1. Pick your distribution:

    sudo apt install libfreetype6 libopenal1 liblua5.1-0 libsdl2-2.0-0
    sudo dnf install SDL2 freetype "lua = 5.1" openal-soft
    sudo pacman -S openal libgl freetype2 sdl2 lua51
    sudo zypper in openal-soft freetype2 SDL2 lua51

    Other distributions: see engine/INSTALL.md. Windows and macOS need nothing extra.

  3. Build and launch

    git clone https://github.com/heshamhabib/rapx.git
cd rapx
make
./launch-game.sh
    git clone https://github.com/heshamhabib/rapx.git
cd rapx
make.cmd
launch-game.cmd

  4. Command

    The game opens with the cinematic intro, then straight to the main menu.
