# RedAlert Project X - soldier turnaround views (ChatGPT)

Back and left-side views of each soldier concept (`assets/units/<id>.png`, front view), used to texture the
soldier's 3D model from every side (artsrc/units/soldiers/). Each prompt attaches the front concept as the
character reference.

  python3 generate_images.py --prompts soldier-views-prompts.md --category units --only views
