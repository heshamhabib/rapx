# RedAlert Project X - Nuclear Missile Silo prompts (RA2-style, 2x2)

Generate with: `python3 artsrc/prompts/generate_images.py --prompts silo-prompts.md --only mslo`
(the Construction Yard style image is attached automatically). Then copy `assets/buildings/mslo.png` to
`artsrc/buildings/src/mslo.png` and run `artsrc/buildings/nuke_silo/make_silo.py`.
The launch bay is painted EMPTY on purpose: make_silo.py stands the 3D missile (the same one that falls on the
target) in it and animates the launch. Design references: artsrc/buildings/nuke_silo/reference/.
