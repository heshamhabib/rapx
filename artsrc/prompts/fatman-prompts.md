# RedAlert Project X - strategic bomber field prompts (USA Fatman, Russia RDS-37)

The Strategic Bomber Field (`bmbf`, 6x4, one parking pad) holds the AB-35 Longwing flying-wing bomber that drops the
Fatman bomb (rules/fatman.yaml). Its single pad must fit a parked flying wing about 4 tiles wide.

Generate with: `python3 artsrc/prompts/generate_images.py --prompts fatman-prompts.md --category buildings --only bmbf`
(the Construction Yard style image is attached automatically); `--only sbmb` for Russia's Long-Range Aviation Base
(rules/tu95.yaml, the Tv-95 Bear with the RDS-37 bomb). Then copy `assets/buildings/bmbf.png` to
`artsrc/buildings/src/bmbf.png`, run `artsrc/buildings/build_all.py` and `artsrc/buildings/make_airfield_slots.py`.
